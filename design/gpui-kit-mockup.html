Mockup
Click systems · hover cards · search (/) · grid/list · delete · Add ROM · About · drag a file onto the window
Look: neutral charcoal surfaces in three steps (window → sidebar/cards → dialogs), 1px borders, small neutral shadows. No gradients or glows. Box art carries the colour; each system's accent is one flat colour (icon tile, active marker, primary button). Games without art get a muted solid tile with a monogram.
Scraping: powered by RetroPie's own Skyscraper (no API keys). Install → auto-scrape that game; Scrape → whole system; cards and the details Sheet read box art, screenshot and description back from gamelist.xml. Covers shown here come from libretro-thumbnails purely as stand-ins.
GPUI Kit mapping: Sidebar/SidebarMenuItem (icon tile, count suffix) · Input + Kbd · ButtonGroup · Button (primary colour from the system accent) · Tag chips · DataTable · Empty · Alert · Sheet · AlertDialog + Collapsible · Dialog + DescriptionList · Notification.
